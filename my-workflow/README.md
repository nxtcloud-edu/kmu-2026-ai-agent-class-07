# my-workflow

Kiro Crew로 내 일 2개 이상을 맡겨 써 보고, 첫 시도와 마지막 시도를 비교합니다. 마감은 수업에서 알립니다.

## 순서

1. 맡길 일을 정하고 [02_기획/기획.md](02_기획/기획.md)를 씁니다. 채운 예는 [01_안내/예시/](01_안내/예시/)에 있습니다. 정하기 어려우면 [01_안내/예시_시나리오.md](01_안내/예시_시나리오.md)를 봅니다.
2. 처음부터 끝까지 한 번 돌립니다. 결과물 파일과 입력을 `04_결과/1_첫_시도/`에 저장합니다. `02_기획/기획.md`를 `02_기획/첫_기획.md`로 복사한 뒤 커밋합니다. `첫_기획.md`는 그 뒤로 고치지 않습니다.
3. 쓰면서 고칩니다. 일지는 작업한 날마다 `05_기록/일지/`에, 고친 것은 그때마다 `05_기록/변경.md`에 씁니다.
4. 같은 입력으로 다시 돌립니다. 결과물 파일과 입력을 `04_결과/2_마지막_시도/`에 저장하고, 쓴 스킬의 마지막 버전을 `03_skills/`에 복사합니다.
5. [06_과제물/KiroCrew_경험.md](06_과제물/KiroCrew_경험.md)를 채워 푸시합니다. 수업에서 한 사람씩 시연합니다. 직접 돌리기 어려우면 녹화나 캡처로 보입니다.

## 폴더

번호 순서대로 씁니다. 폴더 구조는 그대로 두고, 폴더 안의 파일(기획, 일지, 과제물의 표와 칸)은 내 일에 맞게 빼고, 바꾸고, 더해도 됩니다.

| 폴더 | 넣을 것 |
|---|---|
| `01_안내/` | 채운 예(`예시/`), 예시 시나리오, 스킬을 레포에 넣는 방법 |
| `02_기획/` | 처음 돌리기 전에 쓰는 기획(`기획.md`)과 첫 시도 때의 사본(`첫_기획.md`). 바뀌면 `기획.md`만 고칩니다 |
| `03_skills/` | 내가 만든 스킬 폴더의 사본(마지막 버전) |
| `04_결과/` | 결과물 파일과 입력. Slack이나 대시보드로 받은 결과는 파일로 저장하거나 캡처합니다. 일마다 `1_첫_시도/<일 이름>/`처럼 폴더를 만듭니다 |
| `05_기록/` | 작업한 날마다 쓰는 일지, 고친 것(`변경.md`), 캡처 |
| `06_과제물/` | 마지막에 내는 과제물 |

캡처와 결과물에 개인 정보가 보이면 가립니다.
