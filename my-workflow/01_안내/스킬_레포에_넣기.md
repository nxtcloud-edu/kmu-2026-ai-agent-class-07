# 스킬을 레포에 넣기

내가 만든 스킬 폴더를 통째로 `my-workflow/03_skills/`에 복사합니다. 고칠 때마다 복사할 필요는 없습니다. 마지막 시도를 마친 뒤 마지막 버전만 한 번 복사합니다.

## 스킬이 저장된 곳

| | 위치 |
|---|---|
| macOS | `~/.kiro/crew/skills/<스킬 이름>/` |
| Windows | `%USERPROFILE%\.kiro\crew\skills\<스킬 이름>\` |

스킬 폴더 하나에 `SKILL.md`(절차)와 `scripts/`(직접 쓴 코드)가 함께 있습니다. 폴더 안의 파일을 모두 복사합니다. Kiro Crew의 기본 스킬도 같은 폴더에 있으니 내가 만든 스킬만 고릅니다.

## 에이전트에게 맡기기

이 레포를 작업 폴더로 연 Kiro Crew 채팅이나 코딩 에이전트에 그대로 붙여 넣습니다.

```text
내가 Kiro Crew에서 만든 스킬을 이 레포의 my-workflow/03_skills/ 로 복사해 줘.

1. ~/.kiro/crew/skills/ (Windows는 %USERPROFILE%\.kiro\crew\skills\) 의 스킬 폴더를 최근 수정 순으로 보여 줘. 폴더마다 이름, 수정 날짜, SKILL.md의 description을 함께 보여 줘.
2. 내가 고른 스킬만 다뤄. 고르기 전에는 아무것도 복사하지 마.
3. 고른 스킬 폴더를 안의 파일까지 통째로 my-workflow/03_skills/<스킬 이름>/ 으로 복사해 줘. 이미 있으면 덮어써.
4. 복사한 파일에 API 키나 비밀번호가 보이면 커밋하지 말고 그 파일과 줄을 알려 줘.
5. my-workflow/03_skills/ 아래만 git add 하고 "skills: <스킬 이름> 복사" 로 커밋해 줘.
```

## 직접 복사하기

레포 폴더에서 실행합니다.

```bash
cp -R ~/.kiro/crew/skills/<스킬 이름> my-workflow/03_skills/
```

```powershell
Copy-Item -Recurse "$env:USERPROFILE\.kiro\crew\skills\<스킬 이름>" my-workflow\03_skills\
```
