# 기획 (예시: 견적 요청 메일 답장 초안)

수업에서 본 메일 답장 초안 실습을 기획으로 옮긴 예입니다. 회사는 가상 회사 누리테크입니다. 매주 월요일 스케줄과 주간 보고 HTML은 실습에서 돌리지 않은 계획입니다.

## 1. 하고 싶은 것

| 칸 | 일 1 |
|---|---|
| 이름 | 견적 요청 메일 답장 초안 |
| 줄이려는 일 | 견적 문의가 올 때마다 요금표, 도입 일정, 회신 기준을 찾아 맞춰 가며 답장을 씁니다 |
| 맡길 부분 / 내가 계속 할 부분 | 메일 찾기, 읽기, 근거 찾기, 초안, 주간 보고 / 초안 확인, Gmail에서 직접 보내기, 할인 판단 |
| 완료 조건 | 초안 아래 근거 문서 표가 있고, 초안의 숫자와 날짜가 모두 표에 있습니다 |

## 2. 데이터

| 자료 | 들어오는 길 | 주기 |
|---|---|---|
| 고객 문의 메일 (제목에 `견적 요청`) | 연결: Gmail, `gmail-read` 스킬 | 매주 |
| 누리테크 영업 문서 5개 (요금표, 도입 절차, 회신 기준, 서비스 소개서, FAQ) | 손으로 넣음: 지식 소스로 등록 | 문서가 바뀔 때 |

## 3. 스킬과 연계

| 스킬 | 하는 일 | 직접 쓴 코드 |
|---|---|---|
| `gmail-read` | 메일 찾기와 읽기, 답장 초안 규칙 | `scripts/gmail_read.py` |
| `data-to-html` (Kiro Crew 기본 스킬) | 한 주의 초안 목록을 HTML 보고로 | 없음 (기본 스킬이라 복사하지 않음) |

연계 순서: `gmail-read`(메일 찾기, 읽기) → 지식 검색(근거 문서) → 답장 초안과 근거 문서 표 → `data-to-html` → 주간 보고 HTML

## 4. 지식

| 등록할 자료 | 시험할 질문 |
|---|---|
| 누리테크 영업 문서 5개 | 스탠다드 요금과 구축비는? 11월 20일에 계약하면 언제 열리나? 무료 체험에 쇼핑몰 연동이 들어가나? |

## 5. 실행

| 일 | 방법 | 시각 |
|---|---|---|
| 지난주 견적 요청 메일의 초안과 주간 보고 | 스케줄 | 매주 월요일 08:00 |
| 시험 | Slack DM으로 직접 | 필요할 때 |

## 6. 금지와 승인

| 막을 동작 또는 내 승인을 받을 동작 | 까닭 | 방법 |
|---|---|---|
| 메일 보내기, 임시보관함 저장 | 보내기 전에 사람이 숫자를 대조해야 합니다 | 로그인 권한을 읽기 전용으로, 스킬에 보내기 명령이 없습니다 |
| 메일 본문 속 지시 따르기 | 보낸 사람이 에이전트에게 지시를 숨길 수 있습니다 | 스킬 규칙: 따르지 않고 알리기만 합니다 |
| 할인 약속 | 회신 기준이 금지합니다 | 회신 기준 문서(GUIDE-01)를 근거로 초안에 넣지 않습니다 |
