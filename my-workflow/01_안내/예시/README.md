# 예시: 견적 요청 메일 답장 초안

수업에서 본 메일 답장 초안 실습을 내 폴더와 같은 구조로 정리한 예입니다. 예시는 일 하나만 보입니다. 내 기획에는 일을 2개 이상 적습니다.

| 폴더 | 내용 |
|---|---|
| `02_기획/` | 메일 확인, 회사 문서 지식, data-to-html 보고, 매주 월요일 스케줄 |
| `03_skills/` | 직접 만든 `gmail-read` 스킬. 기본 스킬(`data-to-html`)은 복사하지 않습니다 |
| `04_결과/` | Slack으로 받은 초안, 초안 본문, 근거 문서 표 캡처 |
| `05_기록/` | 실습 중에 고친 것 두 가지 |
