# 예시 시나리오

그대로 해도 되고, 바꾸거나 섞어도 됩니다. 내 일로 새로 정해도 됩니다.

| | ① 수업·과제 마감 관리 | ② 채용 공고 점검 | ③ 관심 분야 리서치 브리핑 |
|---|---|---|---|
| 하는 일 | 공지에서 마감을 뽑아 매일 아침 이번 주 할 일을 받습니다 | 관심 직무 공고를 모아 내 경험과 비교합니다 | 새 논문이나 글을 모아 요약합니다 |
| 데이터 | 받은 공지를 `inbox/`에 붙여 넣습니다 | 공개 목록 페이지나 RSS를 스크립트로 가져옵니다 | arXiv 같은 공개 API를 조회합니다 |
| 지식 | 강의계획서 | 내 경험 정리 (개인 정보는 뺍니다) | 이미 읽은 자료와 메모 |
| 스킬과 연계 | 마감 뽑기 → 형식 검사·중복 빼기(코드) | 수집(코드) → 비교 → 원문 검사(코드) | 조회(코드) → 두 관점 분석 → 요약 |
| 실행 | 스케줄 매일 07:30 | 스케줄 매일 08:00 | 스케줄 매일 아침 |
| 사람의 결정 | 모호한 마감을 선택 버튼으로 확정 | 지원할 공고를 고름 | 깊이 읽을 1~2편을 고름 |
| 막을 것 | `data/마감.json` 지우기 | 지원서 제출처럼 밖으로 보내기 | `data/읽음.json` 덮어쓰기 |
| 결과물 | Slack 아침 브리핑, 마감 하루 전 알림 | 맞는 공고 5건과 선택 버튼 | 요약과 깊이 읽기 노트 |
| 고치게 될 것의 예 | 같은 과제가 두 번 잡힘 | 사이트가 바뀌어 0건이 됨 | 요약이 초록을 다시 쓴 수준 |

이미 처리한 것의 목록은 `data/`에 파일로 남깁니다. 가져오기, 중복 빼기, 형식 검사는 코드에 맡기고 판단만 에이전트에게 맡깁니다. 로그인해야 보이거나 이용 약관이 막는 사이트는 스크립트로 가져오지 않습니다.
